# Don't Do List - Frontend

## Overview

Don't Do List is a productivity-focused web application designed to help users reduce bad habits, build better ones, and manage their daily tasks in a more engaging way.

Unlike traditional task managers, Don't Do List focuses on motivation and progress. The application rewards users for their achievements through a game-inspired Trophy System, making personal growth feel more rewarding and enjoyable.

The project follows a friendly and encouraging design philosophy, aiming to help users stay consistent with their goals while enjoying the process.

## Running The Frontend

No build process is required.

To view the frontend locally:

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open any HTML file.
5. Start Live Server.

For example:

```text
index.html
login.html
signup.html
trophy.html
```

Opening any page using Live Server is enough to navigate through the frontend experience.

## Current Frontend Status

The frontend is fully navigable and interactive.

Users can:

- Navigate between pages
- Interact with forms
- Create and manage tasks within the frontend experience
- Explore the Trophy System
- View statistics and achievements

Currently, task data is not permanently stored because backend integration is handled separately.

Authentication state and temporary interactions are managed through browser storage during frontend development.
