# Don't Do List

Don't Do List is a productivity-focused application designed to help users reduce bad habits, build better ones, manage daily tasks, and stay motivated through a game-inspired Trophy System.

The project combines task management, progress tracking, statistics, and achievements to create a more engaging productivity experience.

## Repository Structure

This repository is organized into separate branches for frontend and backend development.

### Frontend Branch

Contains the complete frontend implementation built with:

- HTML5
- CSS3
- Sass (SCSS)
- Vanilla JavaScript

Frontend branch:

```text
feature/frontend
```

---

### Backend Branch

Contains the complete backend implementation built with:

- Python
- Django
- Django Templates
- SQLite3

Backend branch:

```text
feature/backend
```

---

## Which Branch Should I Use?

If you want to:

### Work on the User Interface

Use the frontend branch:

```bash
git checkout feature/frontend
```

### Work on the Backend

Use the backend branch:

```bash
git checkout feature/backend
```

### 🎨 Design Assets

In addition to the frontend and backend code, this repository also includes a design folder.

Inside the `design/` directory you can find:

- Figma preview (UI/UX design reference)
- Screenshots of the full design flow
- Concept previews and layout explorations
- Logo assets and brand elements

This folder helps developers and contributors understand the visual direction of the project and maintain consistency across implementation.

```text
main/design
```

## Project Features

- User Authentication
- Task Management
- Trophy System
- Statistics Tracking
- Daily Progress Monitoring
- Search, Filtering and Pagination
- Password Reset Flow
